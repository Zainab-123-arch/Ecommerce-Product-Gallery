# ShopEase – Responsive E-Commerce Product Gallery

Web Engineering Lab 8 (UET Taxila): CSS Grid layouts and Git/GitHub version control.

## About
A responsive product gallery page built with plain HTML and CSS. The product grid
adjusts the number of columns automatically, without using any media queries.

## Features
- CSS Grid layout using `repeat(auto-fit, minmax(250px, 1fr))` (minimum card width 250px)
- Fully responsive on mobile, tablet and desktop with no media queries
- Hover animations on product cards (lift, shadow, icon zoom) and buttons
- 8 product cards with price, rating, badge and "Add to Cart" button

## Files
| File | Description |
|---|---|
| `index.html` | Page structure and product cards |
| `style.css` | Styling, CSS Grid and hover animations |
| `README.md` | Project description |

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser.
